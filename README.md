### Анализ дроппера и SUID-бэкдора (Linux)

Разбор двух связанных файлов: **bashdoor** (дроппер) и **mcliZokhb** (бэкдор).
Дроппер подменяет bash на версию 2.05, которая не сбрасывает привилегии при SUID,
компилирует бэкдор прямо на хосте и выставляет ему права 6777.
Бэкдор вызывает setuid(0)/setgid(0) и выдаёт root-шелл любому пользователю.
